# مسئله‌ای نی — TM Bax

تجربه تعاملی موزیک برای آهنگ **مسئله‌ای نی** از **TM Bax**

An interactive neon music experience for **Masalei Ni** by **TM Bax**.

---

## ویژگی‌ها

- پخش از طریق SoundCloud (بدون نیاز به آپلود فایل — سازگار با iOS)
- لیریک فارسی همگام با آهنگ
- زیرنویس انگلیسی
- ویژوالایزر نئون
- افکت‌های تعاملی با لمس صفحه
- طراحی شیشه‌ای (Glassmorphism)
- رسپانسیو برای موبایل و دسکتاپ

## اجرا

کافی است `index.html` را باز کنید یا روی GitHub Pages دیپلوی کنید.

### GitHub Pages

1. این ریپو را بسازید / فورک کنید
2. Settings → Pages
3. Source: Deploy from branch → `main` / root
4. چند لحظه صبر کنید تا لینک فعال شود

## فایل‌ها

- `index.html` — کل اپ (تک‌فایلی)
